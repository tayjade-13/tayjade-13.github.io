Retro Collection Game
Python and Pygame, Custom Pixel Art

Description:

A 2D top-down pixel style collection game where the player is the Grinch with the objective of stealing presents from homes around the village without detection from children.

Features I Contributed:

  • AI enemies with sight cones that trigger reactions
  • Collision detection with walls, game objects, and enemies
  • Designed and developed different levels using data structures to manage map generation, object spawning, collision barriers, and asset loading
  • Debug mode for playtesting
GitHub Link:

mabaddomm/Computing-Club-GAME-JAMMMMMMMMMM

Context:

This game was designed and built in one week for a club game jam using an iterative process model. OpenAI was used by my team and I for combining code files quickly, brainstorming bug solutions, and as a tool to overcome the learning curve that was using Pygame utilities for the first time.
